# 焦虑、恐慌与稳定技术

焦虑是校园咨询中最常见的主题之一.你可能因为考试、绩点、保研、就业、家庭期待、社交评价或长期不确定性而出现紧张、心慌、胸闷、手抖、胃部不适、注意力下降、反复检查和灾难化想法.

**重要提醒**:目标不是让你"马上不焦虑",而是帮助你先降低生理唤醒,再把问题拆成可处理的部分.

## 常见表现

**身体反应**
- 紧张、心慌、胸闷
- 手抖、胃部不适
- 睡眠困难、食欲变化

**认知反应**
- 注意力下降
- 反复检查
- 灾难化想法("我一定会失败")

**行为反应**
- 逃避某些场景
- 过度准备或完全无法开始
- 寻求过度安慰

## 支持策略

### 第一步:稳定身体

当你说"我快崩溃了""我心跳很快""我感觉控制不了自己"时,先回应身体和情绪:

> "听起来你的身体正在进入高度警觉状态,这很难受,但我们可以先做一个短步骤让它降下来."

**五感着陆技术(5-4-3-2-1)**

把注意力从灾难化想法拉回当前环境:
1. 说出 **5个** 你看见的东西
2. 说出 **4个** 你能摸到的触感
3. 说出 **3个** 你听见的声音
4. 说出 **2个** 你闻到的气味
5. 说出 **1个** 你尝到的味道

适用于宿舍、图书馆、教室等任何场景.

**4-6呼吸法**

- 用 **4拍** 吸气
- 用 **6拍** 呼气
- 连续 **5轮**

**重点**:延长呼气,而不是憋气.

如果正在明显恐慌,只需要:
> "把双脚踩在地面上,慢慢呼气,比吸气长一点."

### 第二步:整理认知

当身体稍微稳定后,帮助区分三类信息:

**事实**(已发生或可验证)
- "明天有考试"
- "还有三章没复习"

**猜测**(大脑的预警信号)
- "我一定会挂科"
- "老师肯定觉得我很差"

**下一步**(10-30分钟内可完成)
- 列提纲
- 做一道题
- 给同学发消息确认范围
- 洗澡后睡觉

**温和问题**(对抗灾难化思维):
- "最坏情况是什么?"
- "最可能情况是什么?"
- "如果朋友遇到同样情况,你会怎么安慰他?"

**避免说**:"别想那么多"——这常常让学生更挫败.

## 何时寻求专业帮助

如果焦虑持续多周,伴随以下情况,建议尽快联系专业支持:
- 严重失眠
- 频繁惊恐发作
- 逃课、无法考试
- 无法进食
- 反复躯体不适
- 用伤害自己来缓解焦虑

**紧急情况**:如果出现自伤、自杀、伤害他人或立即危险,按高风险处理,立即联系现实中的支持者.

## 校园资源

**可以联系的**:
- 校园心理中心
- 校医院
- 专业机构

**MindBridge可以做的**:
- 提供稳定技巧
- 帮助规划求助路径

**MindBridge不能做的**:
- 诊断焦虑障碍
- 开药或调整药物
- 替代咨询师

如果你正在服药,应联系开药医生或校医院,MindBridge不提供药物调整建议.
